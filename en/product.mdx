---
title: "Run phone and web support in one place"
description: "Prepare an Agent, connect a channel, and review conversations in Overthinker"
---

When phone and web inquiries live in different places, your team has to reconstruct what a customer already said. Overthinker lets you define how an AI Agent responds, connect it to phone or web chat, and review conversations in one place. A human agent can read the conversation before taking over when needed.

## Prepare an Agent

Set the Agent's role, greeting, reference knowledge, and tools. **Deploy it to Live** before you expect changes to affect new conversations on a connected phone number or web chat. Editing a draft alone does not update the deployed Agent.

Voice-call settings are separate from the Agent's response instructions. Changes to speech recognition, voice, interruptions, or call limits apply to conversations started afterward. Calls already in progress keep their existing settings.

## Connect a channel

**Phone:** In Channels, assign an available phone number to a deployed Agent. Disconnecting a number prevents new inbound conversations on that number.

**Web chat:** In Channels, create a web chat endpoint and set both an allowed website Origin and a Live-deployed Agent. Activate it, then add the displayed installation code to the allowed site. An unapproved Origin or an undeployed Agent cannot be activated.

## Review the conversation

Use conversation history to read the transcript and status before the next interaction. Customer management can link earlier conversations by phone number or visitor ID. **Customer memory**, which lets an Agent use facts confirmed in previous conversations, must be enabled separately.

To start calls from your server or install web chat on a website, see the [developer guides](/en/developers/).
