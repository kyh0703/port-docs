Overthinker supports **Agent setup → Live deployment → app conversation → conversation review**. There is no separate channel-management screen. Existing phone and web chat connections remain supported; web chat currently runs **text conversations**. Automatic transfer to a human by phone requires a configured SIP voice call.

| Goal | Start here | What to check |
| --- | --- | --- |
| Build, test, and publish an Agent | [Agents](/en/ai/agents) | The current Live version and the result of a new conversation |
| Adjust voice and conversation behavior | [Voice](/en/ai/voice) | The profile assigned to a channel; changes apply to future voice sessions |
| Connect tools and reference material | [Tools](/en/ai/tools) · [Knowledge](/en/ai/knowledge) | Tool conditions and searchable documents |
| Supply values and check responses | [Variables](/en/ai/variables) · [Evaluations](/en/ai/evaluations) | Inputs at conversation start and test results |
| Review responses and prepare follow-up | [Conversations and customers](/en/operations/conversations) | Transcript, status, and prior conversations |
| Watch an active call | [Monitoring](/en/operations/monitoring) | Your account's call state and live transcript |
| Connect external apps | [Google integrations](/en/operations/integrations) | Your connection state and app tool permissions |
| Check account and plan | [Account and billing](/en/operations/billing) | Plan, balance, and usage history |
| Set privacy or send an inquiry | [Support and privacy](/en/operations/support) | Future conversation policy or inquiry submission |
| Manage the service as an admin | [Administration](/en/operations/admin) | Pricing, inquiries, and runtime controls for authorized accounts |
| Integrate from a server or website | [Overview](/en/developers/) | Server calling API or web chat installation code |

For an end-to-end walkthrough, see [Quickstart](/en/quickstart). Editing a draft does not change the currently running Agent. A test revision may also differ from Live: use **Deploy**, then check the result with a new conversation.
