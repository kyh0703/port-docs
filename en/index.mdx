title: "Introduction to Overthinker"
description: "The building blocks for managing customer conversations across phone and web"
---

Overthinker helps an AI Agent respond to customer inquiries from phone and web, then lets a human agent take over with the conversation context when needed. This site contains public guidance for people using the product.

## AI Agent

Define an Agent's role, greeting, reference knowledge, and tools to establish a consistent response standard. Configure how the Agent responds separately from how the voice call listens and speaks.

## Human handoff

Choose which inquiries the AI handles and when a human agent takes over. The human agent can review the conversation so far before continuing.

## Conversation history

Review phone and web conversations and use the saved context for the next response and operational improvements.
