Overthinker uses AI to handle customer conversations by phone and web chat. Define response rules and reference materials, then connect tools for the tasks your Agent needs to perform.

## Use cases

- Answer customer questions using your instructions and business knowledge.
- Receive calls through connected numbers or place a single call through the server API.
- Add text-based web chat to your website.
- Call external APIs or Google app tools during a conversation to look up or record information.
- Review transcripts and analysis, and transfer configured SIP calls to a human agent.

## How it works

- **Agent**: Uses your instructions, knowledge, and tools to respond and perform tasks.
- **Voice**: Listens with speech recognition (STT) and speaks with speech synthesis (TTS). Adjust voices and conversation behavior in [Voice](/en/ai/voice).
- **App connection**: Uses app authentication and conversation connections. There is no separate channel-management screen.

Draft edits do not immediately affect customers. Use **Deploy** to select a Live version for new production conversations. Existing phone and web chat connections remain available, but user channel creation and configuration are no longer offered. Web chat is currently text-only.

## Agent structure

An Agent can split work across nodes. See [Agents](/en/ai/agents) for setup.

- **Supervisor**: A coordinator delegates tasks to specialists and uses their results.
- **Handoff**: Another node takes over when a condition matches.

Agent handoff is not human transfer. Human transfer requires a configured SIP call; see [Conversations and customers](/en/operations/conversations).

## Features

- **[Tools](/en/ai/tools)**: Connect REST APIs, external MCP and A2A services, and Google apps to an Agent's work.
- **[Knowledge](/en/ai/knowledge)**: Upload documents and select a Revision for the Agent to consult.
- **[Conversations and customers](/en/operations/conversations)**: Review transcripts, analysis, and customer timelines, and manage customer memory.
- **[Monitoring](/en/operations/monitoring)**: Follow the state, transcript, and events of active voice calls on your account.
