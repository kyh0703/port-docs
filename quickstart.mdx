title: "첫 상담 시작하기"
description: "Agent 준비부터 채널 연결, 대화 확인까지 한 번 따라 해요"
---

Overthinker에서 고객과 첫 대화를 시작하려면 **Agent 작성 → Live 배포 → 채널 연결 → 상담 확인** 순서로 진행해요. 초안 저장과 Live 배포는 별개예요. 수정한 내용을 새 대화에 적용하려면 다시 배포해야 해요.

## 1. Agent를 만들고 응대 기준을 정해요

로그인한 뒤 **에이전트**에서 Agent를 만들어요. 어떤 문의를 받을지, 첫 인사와 답변 기준, 필요한 [지식](/ai/knowledge)과 [도구](/ai/tools)를 정하고 **Deploy**로 첫 Live 버전을 배포해요. 그 뒤 편집기에서 텍스트 테스트를 할 수 있어요. 테스트용으로 준비한 새 버전은 Live가 아니므로 수정 내용을 적용하려면 다시 Deploy해야 해요.

자세한 편집과 배포 순서는 [Agent 만들고 배포하기](/ai/agents)를 참고해요.

## 2. 고객이 들어올 채널을 연결해요

**채널 관리**에서 보유한 전화번호에 Live Agent와 사용 가능한 음성 프로필을 연결해요. 웹챗을 만들 때도 Agent·허용 Origin·음성 프로필을 선택하지만, 현재 텍스트 채팅에 음성 프로필은 적용되지 않아요. **API 키**에서 웹챗·Origin에 허용된 Public 키를 만든 뒤 설치 코드를 사이트에 넣어요. 번호가 없으면 전화 채널을 사용할 수 없고, 허용되지 않은 Origin에서는 웹챗을 시작할 수 없어요.

채널별 설정과 확인 방법은 [전화·웹챗 채널 운영](/operations/channels)에 있어요. 서버에서 발신 전화를 만들려면 [개발자 시작하기](/developers/)로 이동해요.

## 3. 상담이 실제로 시작됐는지 확인해요

전화로 걸어 보거나 허용된 사이트에서 웹챗을 열어 질문해요. 전화는 [실시간 대화](/operations/monitoring)에서 연결·전사를 살펴보고, 전화와 웹챗 모두 종료 후 [대화 기록과 고객 관리](/operations/conversations)에서 내용을 확인해요. 요청 접수 또는 Agent 배포만으로 고객과의 통화가 성립한 것은 아니에요.

<Note>
음성 설정 변경은 이미 진행 중인 통화에 적용되지 않아요. Agent 내용과 채널 설정을 바꾸었다면 **새 대화**로 결과를 확인해요.
</Note>
