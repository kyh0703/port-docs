**Agent 작성 → Live 배포 → 새 대화 확인** 순서로 진행해요. 초안 저장과 Live 배포는 별개예요. 수정한 내용을 새 대화에 적용하려면 다시 배포해야 해요.

## 1. 에이전트

로그인한 뒤 **에이전트**에서 Agent를 만들어요. 어떤 문의를 받을지, 첫 인사와 답변 기준, 필요한 [지식](/ai/knowledge)과 [도구](/ai/tools)를 정하고 **Deploy**로 첫 Live 버전을 배포해요. 그 뒤 편집기에서 텍스트 테스트를 할 수 있어요. 테스트용으로 준비한 새 버전은 Live가 아니므로 수정 내용을 적용하려면 다시 Deploy해야 해요.

자세한 편집과 배포 순서는 [에이전트](/ai/agents)를 참고해요.

## 2. 연결

별도의 **채널 관리** 화면과 사용자 전화번호 연결·웹챗 생성 API는 제공하지 않아요. 앱 인증과 대화 연결, 기존 전화·웹챗 연결은 유지돼요.

운영 배포본의 응답은 [Live 테스트](/ai/evaluations)로 확인해요. 기존 번호로 서버에서 전화를 걸려면 [개발자 개요](/developers/)를 참고해요. 기존 웹챗 엔드포인트가 있는 경우에만 [웹챗 설치 가이드](/developers/web-chat)를 사용해요.

## 3. 첫 대화

앱이나 Live 테스트에서 새 대화를 시작해 질문해요. 기존 전화 연결을 사용하는 경우 [실시간 대화](/operations/monitoring)에서 연결·전사를 살펴봐요. 종료 후에는 [대화 기록과 고객 관리](/operations/conversations)에서 내용을 확인해요. 요청 접수 또는 Agent 배포만으로 고객과의 통화가 성립한 것은 아니에요.

<Note>
음성 설정 변경은 이미 진행 중인 통화에 적용되지 않아요. Agent 내용이나 음성 설정을 바꾸었다면 **새 대화**로 결과를 확인해요.
</Note>
