Overthinker는 AI Agent의 응대 기준을 정하고, 전화와 웹챗으로 고객을 만나고, 상담 결과를 확인하는 서비스예요. 반복되는 문의는 Agent가 처리하고, 필요한 업무는 도구로 연결해요. 상담이 끝난 뒤에는 대화 기록과 고객 이력을 바탕으로 다음 응대를 준비할 수 있어요.

## 어떤 일을 할 수 있나요?

- 준비한 안내와 업무 지식으로 고객의 질문에 답해요.
- 연결된 전화번호로 전화를 받고, 한 건의 전화나 발신 캠페인을 시작해요.
- 웹사이트에 텍스트 웹챗을 설치해 문의를 받아요.
- 대화 중 외부 API나 Google 앱 도구를 호출해 조회·등록 같은 업무를 처리해요.
- 상담 기록과 분석을 확인하고, 설정된 SIP 통화에서는 사람 상담원에게 연결해요.

## 어떻게 작동하나요?

**Agent 작성 → Live 배포 → 채널 연결 → 상담 확인** 순서로 사용해요.

Agent에는 역할, 답변 기준, 참고할 지식과 사용할 도구를 정해요. 전화 상담에서는 음성 인식(STT)이 고객의 말을 텍스트로 바꾸고, 실행 모델(LLM)이 답변이나 도구 호출을 결정해요. 음성 합성(TTS)은 답변을 목소리로 전달해요. 목소리와 끼어들기·침묵 같은 동작은 [음성 프로필과 대화 설정](/ai/voice)에서 조정해요.

수정 중인 초안은 고객 상담에 바로 반영되지 않아요. **Deploy**로 Live 버전을 정하고 전화번호나 웹챗을 연결하면 새 대화가 그 배포본을 사용해요. 웹챗은 현재 텍스트 전용이에요.

## Agent의 역할을 나눠요

한 Agent 안에 여러 노드를 두고 업무를 나눌 수 있어요. [Agent 만들기](/ai/agents)에서 응대 방식에 맞는 구성을 선택해요.

- **Supervisor**: 총괄 노드가 전문 노드에 작업을 맡기고 결과를 받아 대화를 이어가요.
- **Handoff**: 조건에 따라 다른 노드가 대화 주도권을 넘겨받아요. 접수에서 상세 안내로 넘어가는 것처럼 담당 역할이 바뀌는 흐름을 구성해요.

Agent 노드 간 전환과 사람 상담원 연결은 다른 기능이에요. 사람 연결은 [상담사 전환 도구와 SIP 통화 조건](/operations/conversations)을 확인해요.

## 주요 기능

- **[도구](/ai/tools)**: REST API, 외부 MCP·A2A, Google 앱을 Agent의 업무에 연결해요.
- **[지식 검색](/ai/knowledge)**: 문서를 업로드하고 검색할 Revision을 지정해 답변에 참고하게 해요.
- **[채널](/operations/channels)**: 계정에 배정된 전화번호나 웹사이트의 웹챗을 Live Agent에 연결해요.
- **[발신 캠페인](/operations/campaigns)**: 동의 증빙이 있는 수신자 CSV를 검토하고 순차 발신해요.
- **[대화 기록과 고객](/operations/conversations)**: 전사·분석·고객별 상담 이력을 확인하고 고객 메모리를 관리해요.
- **[실시간 대화](/operations/monitoring)**: 내 계정의 진행 중 음성 통화 상태와 전사·이벤트를 살펴봐요.
