Overthinker를 연결할 때는 **서버에서 전화를 시작하는 경우**와 **방문자의 브라우저에 웹챗을 넣는 경우**를 먼저 구분해요. 두 방식은 키를 공유하지 않아요.

| 하려는 일 | 사용할 키 | 보관할 곳 |
| --- | --- | --- |
| 서버에서 발신 통화 만들기·조회 | Private API 키 (`ot_sk_`), 또는 기존 발신용 키 (`ot_call_`) | 서버의 비밀 저장소 |
| 웹사이트에 웹챗 설치 | 해당 Origin과 웹챗에 허용된 Public API 키 (`ot_pk_`) | 설치 스크립트의 `data-public-key` |

브라우저 코드, 공개 저장소, 설치 스크립트에는 **Private 키를 넣지 마세요**. 기존 MCP·A2A 전용 키(`ot_mcp_`)는 통화 생성에 사용할 수 없어요. 키는 로그인한 Overthinker의 **API 키** 화면에서 관리해요. Private 키 값은 발급할 때 한 번만 볼 수 있어요.

## 요청 주소

HTTP API 경로는 `/api/v1`로 시작해요. 이 문서에는 고정된 외부 API 호스트를 싣지 않아요. 서버에서 요청을 보낼 때는 계정에서 접속하는 Overthinker 주소의 **Origin**에 아래 문서의 경로를 붙이고, 서버가 그 주소에 접근할 수 있는지 확인해요. 내부 서비스 주소나 브라우저의 비밀 쿠키를 서버 연동용 주소·인증 수단으로 사용하지 마세요.
