---
title: "기존 웹챗 설치"
description: "이미 생성된 웹챗 엔드포인트와 Public 키로 기존 웹사이트 연동을 유지해요"
---

웹챗은 고객이 접속한 페이지에서 실행돼요. 서버 발신에 사용하는 Private 키를 설치 코드에 넣지 말고, **웹챗 전용 Public API 키**를 사용해요.

## 준비

1. 내 계정에 이미 생성된 활성 웹챗 엔드포인트와 연결된 Agent의 **Live 배포본**이 있어야 해요. 채널 관리 화면과 엔드포인트 생성·변경 API는 제공하지 않아요.
2. 기존 엔드포인트에 허용된 Origin과 웹사이트의 실제 Origin이 일치해야 해요. `https://example.com`과 `https://www.example.com`은 달라요.
3. **API 키 → Public API 키**에서 해당 기존 웹챗과 Origin을 허용하는 키를 만들어요. 기존 키가 둘 다 허용한다면 그대로 쓸 수 있어요.
4. 기존 설치 코드나 `GET /api/v1/web-chat/endpoints` 응답의 `publicId`로 엔드포인트를 확인해요. 이 조회에는 내 계정 인증이 필요해요.

## 설치 코드

기존 엔드포인트의 공개 ID와 Public 키를 사용해 사이트의 HTML에 아래 스크립트를 넣어요. 주소·웹챗 ID·공개 키를 임의로 만들지 마세요. 사용자 화면에서 새 엔드포인트나 설치 코드를 생성하지는 않아요.

```html
<script src="<Overthinker 접속 주소>/web-chat/loader.js"
        data-endpoint="<웹챗 공개 ID>"
        data-public-key="<Public API 키>"
        async></script>
```

방문자가 허용된 Origin에서 페이지를 열면 로더가 웹챗 창을 표시하고 대화 세션을 시작해요. 브라우저의 공개 키는 비밀이 아니지만, 키가 허용하는 Origin과 웹챗은 서버에서도 검사해요. Private 키는 브라우저에 보내지 않아요.

## 문제 해결

- **엔드포인트가 없어요:** 새 엔드포인트 생성은 지원하지 않아요. 이 가이드는 기존 엔드포인트가 있는 경우에만 적용돼요.
- **403:** 페이지의 실제 Origin과 채널·키에 설정한 Origin이 일치하는지, 키가 해당 웹챗에 허용됐는지 확인해요.
- **404:** 웹챗이 활성 상태인지, 연결한 Agent에 Live 배포본이 있는지 확인해요.
- **429:** 웹챗 시작 요청 제한에 걸렸어요. 새로고침을 반복하지 말고 잠시 뒤 다시 확인해요.

웹챗에서 시작한 대화는 텍스트 대화예요. 기존 음성 프로필은 이 대화에 음성을 추가하지 않아요. 새 키를 발급했다면 기존 엔드포인트와 키의 허용 범위를 확인하고 설치 코드를 갱신해요. 기존 엔드포인트에 허용되지 않은 Origin으로는 사용할 수 없어요.
