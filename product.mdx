title: "기능 안내"
description: "Agent 작성부터 고객 응대, 상담 기록과 운영까지 기능별로 찾아봐요"
---

Overthinker는 **AI Agent 작성 → Live 배포 → 앱에서 대화 → 대화 확인**을 지원해요. 별도의 채널 관리 화면은 제공하지 않아요. 기존 전화·웹챗 연결은 유지되며 웹챗은 현재 **텍스트 대화**예요. 사람 상담원으로의 자동 전화 연결은 설정된 SIP 음성 통화에서만 가능해요.

| 목표 | 어디에서 시작하나요? | 확인할 결과 |
| --- | --- | --- |
| Agent 작성·테스트·배포 | [에이전트](/ai/agents) | 현재 Live 버전과 새 대화의 응답 |
| 음성·대화 방식 조정 | [음성](/ai/voice) | 채널에 연결된 프로필; 다음 음성 세션부터 적용 |
| 외부 도구·참고 자료 연결 | [도구](/ai/tools) · [지식](/ai/knowledge) | 도구 사용 조건과 검색할 문서 |
| 필요한 값·응답 품질 확인 | [변수](/ai/variables) · [평가](/ai/evaluations) | 대화 입력값과 테스트 결과 |
| 응대 검토·재방문 준비 | [대화와 고객](/operations/conversations) | 전사, 상태, 고객별 이전 상담 |
| 진행 중 통화 확인 | [모니터링](/operations/monitoring) | 내 계정의 통화 상태와 실시간 전사 |
| 외부 앱 연결 | [Google 연동](/operations/integrations) | 내 계정 연결 상태와 도구에 사용할 권한 |
| 플랜·계정 확인 | [계정과 요금](/operations/billing) | 플랜, 잔액과 사용 이력 |
| 개인정보·문의 처리 | [문의와 개인정보](/operations/support) | 다음 대화의 보호 범위 또는 문의 접수 상태 |
| 운영자 전용 관리 | [관리자](/operations/admin) | 권한이 있는 계정의 요금·문의·실행 관리 |
| 서버·웹사이트에 연동 | [개발자 개요](/developers/) | 서버 발신 API 또는 웹챗 설치 코드 |

처음부터 한 번 따라 하려면 [빠른 시작](/quickstart)을 이용해요. Agent 초안을 고친 것만으로 운영 중인 Agent가 바뀌지 않아요. 테스트용 버전도 현재 Live와 다를 수 있으므로 채널에서 사용할 변경은 **Deploy** 후 새 대화로 확인해요.
