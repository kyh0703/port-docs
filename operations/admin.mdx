---
title: "관리자"
description: "관리자 권한으로 요금·프로모션·문의·제공자 설정과 운영 기록을 점검해요"
---

**관리자 역할**로 로그인해야 아래 화면을 사용할 수 있어요. 일반 사용자에게는 요금 수정, 프로모션 등록, 문의 상태 변경, 제공자 키·음성 런타임 설정 권한이 없어요.

| 확인할 항목 | 서비스 화면에서 할 일 | 확인할 결과 |
| --- | --- | --- |
| 운영 요약 | **대시보드**(`/admin/dashboard`)를 열어요. | 오늘(KST)·전체 가입자 수와 콜 발생 수 4개만 표시돼요. 세계 단위 고객 분석 지표가 아니에요. |
| 가입자 조회 | **가입자 관리**(`/admin/users`)에서 **전체 이메일·E.164 전화번호·가입자 UUID**로 검색하고 권한·이메일 인증 상태로 필터링한 뒤 상세를 열어요. | 계정·인증 정보와 가입일을 조회해요. 이 화면에서 권한이나 가입자 정보를 편집하지 않아요. |
| 문의 처리 | **문의 관리**(`/admin/inquiries`)에서 전체·신규·처리 중·완료로 필터링하고 상세에서 **처리 상태 저장**을 눌러요. | **문의 상태를 저장했습니다**가 표시돼요. 다른 관리자가 먼저 바꿨다면 **최신 내용 불러오기** 후 다시 수정해요. |
| 알림톡 발송 | **알림톡 입력 관리**(`/admin/form-collections`)에서 서버 준비 상태를 확인하고 **새 알림톡 발송 허용**을 변경·저장해요. | 기본값은 OFF예요. 서버 설정이 준비되지 않으면 ON으로 저장할 수 없어요. ON은 허용 상태일 뿐 발송 성공을 뜻하지 않아요. OFF여도 이미 발급한 폼은 만료 전까지 제출할 수 있어요. |
| 상담 지식 | **상담 지식베이스**(`/admin/support-knowledge`)에서 공용 상담 문서를 한 번에 하나씩(50MB 이하) 등록·재색인·삭제해요. | 업로드 요청 성공 후 목록의 처리 상태·오류를 확인해요. 공개 상담 AI용이며 계정별 [Agent 지식](/ai/knowledge)과 별개예요. |
| 공통 프롬프트 | **프롬프트 관리**(`/admin/prompt-config`)에서 시스템 가드레일, Handoff·Supervisor, 음성·키패드 규칙을 검토해요. | 조합 미리보기로 범위를 확인하고 변경을 저장해요. 새 대화부터 적용되는 공유 설정이며 개별 Agent 지침과 별개예요. |
| 충전 요금 | **요금제 관리**(`/admin/pricing`)에서 분당 원화 요금, 최소·최대 충전 시간과 충전 단위를 입력해 **요금 설정 저장**을 눌러요. | 저장 완료 메시지가 표시돼요. 최소·최대 시간은 단위의 배수여야 하고, 충돌이 나면 **최신 설정 불러오기** 후 다시 수정해요. 새 주문부터 적용되며 기존 주문·잔액은 유지돼요. 충전 결제 자체의 활성 여부는 별개예요. |
| 프로모션 | **프로모션 코드 관리**(`/admin/promotion-codes`)에서 정률 또는 정액 할인, 적용 기간, 활성 여부를 정해 등록해요. | 목록에 코드가 나타나고 활성 상태를 변경할 수 있어요. 고객 할인은 결제가 활성화된 환경에서 해당 코드로 주문할 때만 확인해요. |
| 제공자 키·음성 | **연동 및 키 관리**(`/integrations`)의 **제공자 API 키**에서 등록·교체 후 **등록됨**을 확인해요. **음성 런타임 관리**(`/admin/voice-runtime`)에서 활성 STT/TTS 옵션·기본값과 음성을 확인하고 저장해요. | 기본 STT/TTS는 활성 상태여야 하고 기본 음성은 활성 TTS와 호환돼야 해요. 키 원문 대신 등록 상태가 표시돼요. Google OAuth·고객 API 키와는 별개예요. |
| 실행 기록·비용 | **LLM 사용 기록**(`/admin/llm-audit`)에서 대화 ID·모델·상태로 검색하고, **대화 비용**(`/admin/conversation-costs`)에서 대화를 골라 **비용 상세**를 열어요. | 요청·비용 상태를 각각 확인해요. 제공자 사용량이 누락됐다고 사용량이 0인 것은 아니고, 추정 비용은 확정 청구액이 아니에요. |

<Note>
  요금과 프로모션 화면이 있다는 사실만으로 실제 고객 결제가 활성화됐다고 볼 수 없어요. 사용자에게 충전을 안내하기 전에 [계정과 이용 시간](/operations/billing)의 화면 결과를 확인해요. **실시간 대화**(`/monitoring`)는 관리자 전체 계정 관제 화면이 아니라 로그인한 계정의 통화만 보여줘요.
</Note>
