응대 결과를 검토하려면 **대화 기록**과 **고객**을 함께 확인해요. 진행 중 통화에 사람이 들어가야 한다면 대화 상세에서 참여할 수 있어요.

## 대화 기록

1. **대화 기록**에서 상태를 선택하고 날짜·감정·종료 주체로 좁히거나 제목·마지막 발화·저장된 요약을 검색해요. 검색과 일부 필터는 **현재 불러온 페이지**에 적용되므로 필요한 기록이 보이지 않으면 더 불러와요.
2. 대화를 열어 전사와 종료 정보, **통화 정보 · 분석 · 비용**, **전체 실행 성능 · 모델 비용**을 확인해요. 고객이 연결되어 있으면 **고객 상세 보기**로 이동할 수 있어요.
3. 종료된 배포 상담의 요약·고객 감정이 보이지 않으면 **분석 시작** 또는 **분석 다시 시도**를 눌러요. 처리 중에는 결과가 갱신돼요. 진행 중인 대화는 이 분석 대상이 아니며, 고객 발화가 부족하거나 전사가 너무 길면 분석이 생략·실패할 수 있어요.

## 고객과 메모리

**고객**에서 이름이나 식별자로 찾거나 **고객 추가**에서 이름 또는 전화번호·이메일·외부 ID 등 식별자를 입력해 등록해요. 상세에서 이름·메모·고객 속성을 고치고 아래 **고객 상담 타임라인**에서 해당 고객의 전화·웹챗 상담을 열어 봐요. 전화와 웹 방문자 ID가 자동으로 한 고객으로 합쳐진다고 가정하지 마세요.

고객 상세의 **고객 메모리**에서 Agent를 선택해 **지속 정보** 또는 **최근 상황**을 직접 추가·삭제할 수 있어요. 같은 곳의 Agent별 **고객 메모리** 스위치를 켜야 종료된 상담에서 기억을 자동으로 추출해 **다음 상담**에 활용해요. 고객 연결과 상담 기록은 스위치와 별개예요. 자동 추출은 연결된 배포 상담이 종료되고 의미 있는 고객 발화가 있을 때 비동기로 처리되므로 곧바로 나타나지 않을 수 있어요. 기억은 Agent별이며 모든 Agent가 공유하지 않아요.

## 상담원 연결

- **Agent 사이의 전환**은 [Agent 편집기](/ai/agents)의 노드 간 전환이에요. 사람에게 전화를 거는 기능이 아니에요.
- **상담사 자동 전환**은 **도구 → 상담사 전환**에서 호출 조건·전화번호 또는 SIP URI·벨 울림 제한 시간·연결 방식(바로 연결/상담사 확인 후 연결)을 저장해 Agent 노드에 연결하고 Live로 배포해요. **활성 AI 제어 SIP 음성 통화**에서만 실행돼요. 확인 후 연결 방식은 상담사 브리핑 후 음성·키패드 또는 대화 상세의 **SIP 전환**에서 수락/거절할 수 있어요. 거절·실패 시 AI 복구를 시도하며, 완료되면 사람 통화로 바뀌어요. 웹챗·텍스트·WebRTC 테스트에는 이 SIP 전환을 사용할 수 없어요.
- **운영자 직접 참여**는 **대화 기록 → 활성 음성 대화 → 통화 정보 · 분석 · 비용 → 통화 참여**에서 브라우저 마이크 권한을 허용해요. 웹 참여가 연결되고 활성 SIP 고객이 있으며 아직 AI 통화 중이라면 **직접 통화로 전환**으로 사람 통화를 이어받을 수 있어요. 같은 배포본에 묶인 활성 번호로 제3자에게 전화해 초대할 수도 있어요. 종료된 통화에서는 참여할 수 없어요.
