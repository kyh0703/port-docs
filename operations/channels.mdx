---
title: "채널"
description: "Live Agent에 전화번호나 웹챗을 연결하고 첫 대화를 확인해요"
---

고객에게 전화나 웹챗을 열려면 먼저 [Agent를 Live로 배포](/ai/agents)하고 **사용 가능한 음성 프로필**을 준비해요. 초안을 저장하는 것만으로 운영 채널은 바뀌지 않아요. 새 대화는 현재 Production 배포본을 사용해요.

## 전화

1. **채널 → 전화번호**에서 연결할 Agent와 음성 프로필을 선택해 **전화번호 연결**을 눌러요. 이미 번호가 있다면 해당 번호의 **연결 대상**과 **음성 프로필**을 설정해요.
2. 번호에 **active** 상태와 연결 대상이 표시되는지 확인하고, 실제 번호로 전화를 걸어 새 인바운드 상담을 확인해요. 사용 가능한 번호는 계정에 먼저 배정돼 있어야 해요. 이 화면에서 번호를 직접 구매하거나 등록하지는 못해요.
3. 한 건을 발신하려면 같은 화면의 **전화 발신**을 열고 Live Agent, 그 Agent에 연결된 활성 발신 번호, E.164 형식 수신 번호(`+`와 국가번호), 배포본이 요구하는 통화 변수를 입력해요. 결과의 대기·연결·종료·실패 상태를 확인하고 대화가 생성되면 **통화 내역 보기**로 이동해요.

번호 연결을 해제하면 **reserved**로 바뀌어 새 인바운드 전화를 받지 않아요. 발신 번호가 목록에 없으면 번호의 활성·배정 상태와 Agent의 Live 배포를 확인해요. 발신 결과가 **확인 필요**라면 성공으로 간주하거나 곧바로 다시 발신하지 말고 상태를 확인해요. 전화 시작에는 사용 가능한 통화 시간이 필요해요.

## 웹챗

1. **채널 → 웹챗**에서 이름, 사이트의 정확한 **허용 Origin**, Live Agent와 음성 프로필을 선택해 **웹챗 만들기**를 눌러요. Origin은 프로토콜·호스트·포트를 포함해요. 예를 들어 `https://example.com`과 `https://www.example.com`은 달라요.
2. **API 키 → Public API 키**에서 해당 웹챗 엔드포인트와 Origin을 허용하는 `ot_pk_` 키를 발급해요. **채널 → 웹챗**에 표시된 **설치 코드**를 복사해 허용한 사이트의 HTML에 넣어요. 설치 코드가 없으면 키의 엔드포인트·Origin 범위를 확인해요.
3. 허용한 사이트를 열어 웹챗 버튼을 누르고 텍스트를 보내 응답을 확인해요. 시작되지 않으면 엔드포인트가 활성 상태인지, Agent에 Live 배포가 있는지, 실제 페이지 Origin과 채널·키에 허용한 Origin이 일치하는지 확인해요.

<Note>
웹챗은 현재 **텍스트 전용**이에요. 생성에 필요한 음성 프로필을 선택해도 웹챗에서 음성이 재생되지는 않아요. 브라우저에는 Public 키만 넣고 서버용 Private 키는 넣지 마세요. 설치 방법은 [웹챗 설치 가이드](/developers/web-chat)를 참고해요.
</Note>
