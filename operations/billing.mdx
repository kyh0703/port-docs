title: "계정과 요금"
description: "프로필·플랜·잔액·구매 거래를 확인하고, 활성 환경에서만 통화 시간을 충전해요"
---

로그인 후 **설정**에서 내 계정과 이용 시간을 확인해요. 플랜 현황은 조회 전용이고, 선불 통화 시간 구매는 결제가 활성화된 환경에서만 가능해요.

<Steps>
  <Step title="프로필 확인">
    **설정 → 프로필**에서 이름과 전화번호를 고쳐 **저장**해요. 다시 표시된 값을 확인해요. 이메일은 읽기 전용이며 비밀번호·소셜 로그인은 인증 제공자에서 관리해요.
  </Step>
  <Step title="플랜 현황 확인">
    **설정 → 플랜 현황**에서 상태, 기간, 할당·사용·남은 통화 시간을 확인해요. 지급된 플랜이 없으면 **현재 구독이 없습니다**가 보여요. 여기서 플랜을 직접 가입·변경·해지하거나 정기 결제할 수는 없어요.
  </Step>
  <Step title="잔액과 구매 거래 확인">
    **설정 → 잔액 & 사용이력**에서 사용 가능·예약된 시간과 충전·사용 증감 내역을 확인해요. **더 보기**로 다음 거래를 볼 수 있어요. **설정 → 청구서**에는 구매 거래만 날짜·원화 금액·완료 상태로 표시돼요. 구매가 없다면 **청구서가 없습니다**가 보여요.
  </Step>
</Steps>

<Note>
  **청구서**는 구매 거래 목록이에요. PDF 다운로드, 영수증·세금계산서 발급 화면이 아니에요. 플랜 관련 요청이나 계정 문제는 [문의하기](/operations/support)를 이용해요.
</Note>

## 통화 시간 충전

**설정 → 잔액 & 사용이력 → 충전하기** 또는 **결제 수단**을 열어 표시된 최소·최대 시간과 충전 단위에 맞춰 분을 입력해요. 프로모션 코드가 있다면 입력하고, 결제 준비 화면에서 할인과 최종 원화 금액을 확인한 뒤 **카드**로 결제해요. 성공 화면이 나온 뒤 잔액과 충전 거래를 다시 확인해요.

결제는 기본 설정에서 꺼져 있어요. 실제 구매 화면에 **결제를 사용할 수 없습니다**가 표시되면 진행할 수 없어요. 선불 시간의 확인된 사용 경로는 웹 음성(WebRTC)이에요. SIP 발신은 플랜의 통화 시간 조건을 사용하므로 선불 잔액이 모든 통화에 적용된다고 가정하지 마세요.
