title: "지식"
description: "파일 업로드부터 Revision 생성, 지식 도구 발행과 Agent 연결까지 진행해요"
---

답변의 참고 자료로 파일을 쓰려면 **문서 업로드 → 준비됨 확인 → Revision 생성 → 지식 도구 발행 → Agent 연결** 순서로 진행해요. 로그인하고 PDF, DOCX, PPTX, XLSX, MD, UTF-8 TXT, HWP, HWPX 중 하나를 준비해요. 한 번에 파일 **1개, 최대 50 MiB**까지 올릴 수 있어요.

## 문서 업로드

**지식 관리 > 문서 업로드**에서 파일을 선택하고 화면의 **지식 키**를 입력한 뒤 **등록**해요. 지식 키는 영문 소문자로 시작하고 소문자·숫자·밑줄만 사용해요. 등록 메시지는 처리 요청을 받았다는 뜻이에요. **등록된 지식** 목록에서 상태가 `처리 중`에서 `준비됨`으로 바뀔 때까지 확인해요.

<Note>
현재 업로드 화면의 지식 키가 검색 식별자로 그대로 보존된다고 가정하지 마세요. 검색 대상은 다음 단계에서 선택하는 **Revision**이에요. **URL로 지식 등록**과 **FAQ 직접 입력**은 화면에 보여도 비활성 상태예요.
</Note>

## 검색 버전

목록에서 `준비됨` 문서를 하나 이상 체크하고 **선택 문서로 Revision 생성**을 눌러요. **도구모음 > 도구 추가 > 지식 검색**에서 표시 이름, Function Name, 어떤 질문에 이 자료를 검색할지 알려 주는 설명을 적고 방금 생성된 **Knowledge revision**을 골라 **저장**해요. 도구모음에서 저장을 완료하면 `v1` 같은 발행 버전이 자동 생성돼요. 상세 상단의 버전을 확인해요. Revision은 생성 시점의 문서 내용을 고정하므로 나중에 파일을 더 올려도 기존 Revision이 자동으로 바뀌지 않아요.

## 에이전트 연결

[Agent 편집기](/ai/agents)의 해당 노드에 발행된 지식 도구를 연결하고 **Deploy**해요. 새 테스트 대화에서 업로드한 문서로 답할 수 있는 질문을 해 보고 도구 실행 표시와 실제 답변을 확인해요. 문서를 바꾸려면 `준비됨`을 다시 확인한 뒤 새 Revision을 만들어 도구 참조를 수정·저장하고 새 발행 버전을 확인해요. Agent가 특정 도구 버전에 고정돼 있다면 새 버전을 선택하고 Agent도 다시 **Deploy**한 뒤 새 대화로 점검해요.

<Note>
상태가 `실패`이면 목록의 오류를 확인하고 파일을 수정해 다시 업로드하거나 **재색인**을 시도해요. HWP/HWPX는 텍스트·표를 추출하지만 이미지 OCR, 원본 레이아웃 및 원본 페이지 번호 인용은 제공하지 않아요. 암호로 보호되거나 손상된 파일은 처리에 실패할 수 있어요.
</Note>
