도구를 쓰려면 로그인한 계정의 **도구모음**에서 도구 버전을 발행하고, [Agent](/ai/agents)의 사용할 노드에 연결해야 해요. 외부 서비스 도구라면 호출할 endpoint와 필요한 인증 정보를 먼저 준비해요.

## 도구 종류

**도구모음 > 도구 추가**에서 종류를 고르고 설정한 뒤 **저장**해요.

| 종류 | 입력·동작의 경계 |
| --- | --- |
| REST API | Function Name, 설명, GET/POST/PUT/PATCH/DELETE 중 메서드, endpoint URL, 입력 JSON Schema를 지정해요. 출력 Schema는 선택 사항이에요. 인증은 없음, API key(`X-API-Key`), Bearer(`Authorization: Bearer …`) 중 하나로 설정하고 비밀값을 입력해요. |
| MCP · A2A | 각각 **외부 MCP 서버**(SSE 또는 Streamable HTTP)와 **외부 Agent Card URL**을 도구로 *소비*해요. endpoint와 없음/API key/Bearer 인증을 준비해요. 내 Overthinker Agent를 외부 A2A 클라이언트에 실행 서비스로 공개하는 설정은 아니에요. |
| Google 앱 | **연동 및 키 관리 > 내 Google 계정**에서 해당 앱을 먼저 연결해요. Sheets는 발행 시 정한 시트 ID·범위에 행 추가만 해요(요청당 최대 100행, 행당 100셀). Calendar는 캘린더 ID·시간대를 정해 일정 만들기 또는 빈 시간 확인 중 하나를 골라요. 시간은 해당 시간대와 일치하는 UTC 오프셋 포함 RFC3339로 입력하고 조회·일정 구간은 최대 90일이에요. Gmail은 메일 읽기·발송뿐 아니라 삭제 등 변경 작업도 포함하므로 권한과 사용 조건을 확인해요. |
| 지식 검색 | [지식 관리](/ai/knowledge)에서 Revision을 먼저 만들어요. |
| 상담원 연결 | 전화번호 또는 SIP URI를 지정하는 **설정된 SIP 음성 통화용** 도구예요. 웹챗에서 사람에게 자동 전화 연결하는 기능은 아니에요. |

## 저장과 발행

**도구모음**에서 새 도구를 **저장**하면 Draft 설정이 적용되고 `v1` 같은 발행 버전이 자동 생성돼요. 같은 화면의 도구 상세에서 수정 후 **저장**해도 새 `vN`이 발행돼요. 상세 상단의 버전 번호를 확인해요. 저장에 실패하거나 버전이 없는 Draft는 Agent에 연결할 수 없어요. 별도의 도구 상세 주소(`/tools/<toolId>`)에서 편집하는 경우에는 변경이 Draft로 자동 저장되므로, **배포**를 눌러 버전 이름을 입력해야 발행돼요.

## 에이전트 연결

Agent 편집기의 사용할 노드에서 발행된 도구를 선택하고, **버전**을 `최신` 또는 특정 `vN`으로 정해요. `최신`은 새 대화에서 현재 발행본을 사용하고, 특정 버전 고정은 새 도구 버전이 나와도 그 버전을 유지해요. Agent를 **Deploy**한 뒤 새 테스트 대화에서 도구가 필요한 질문을 해 보세요. 테스트 전사에 도구 이름과 **완료/실패** 표시가 나오고 의도한 응답 또는 외부 서비스 결과가 있는지 확인해요. 테스트용 버전과 Live 버전은 다를 수 있으니 운영 채널도 **새 대화**로 확인해요.

<Note>
호출에 실패하면 도구 발행본·Agent Live 배포 여부, endpoint와 인증 권한을 확인해요. Google 연결을 해제하거나 새 계정으로 다시 연결했다면 기존 발행본이 새 권한을 자동으로 이어받지 않아요. 새 연결로 도구를 다시 만들고 발행·연결해요.
</Note>
