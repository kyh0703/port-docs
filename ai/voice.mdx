description: "프로필을 만들고 전화 채널에 연결해 새 음성 세션의 말하기·종료 동작을 조정해요"
---

목소리는 Agent 편집기가 아니라 **음성 프로필과 채널**에서 선택해요. 로그인한 뒤 앱의 **음성 프로필**(`/dashboard/settings/voice-profiles`)에서 시작해요. 프로필을 저장하려면 관리자가 사용 가능한 STT·TTS 모델과 제공자 키를 준비해야 해요.

## 음성 프로필

1. **음성 프로필 추가**를 눌러 이름을 입력해요. **목소리**에서 TTS 모델과 호환되는 음성을 고르고 미리 들어요.
2. **음성 인식 · STT**에서 제공자·모델을 선택하고, 회사명처럼 정확히 인식해야 할 용어를 줄마다 입력해요(최대 100개, 항목당 100자).
3. 필요하면 응답 속도·사용자 끼어들기, 노이즈 제거·발화 민감도·배경음, DTMF 입력과 발신 연결 대기를 조정해요. **프로필 만들기**를 눌러요.
4. 목록에 **사용 가능** 상태와 revision이 표시되는지 확인해요. 여러 프로필 중 하나를 **기본 지정**할 수 있어요. 기본 프로필은 새 채널 연결의 초기 선택값이며, 프로필을 지정하지 않은 직접 브라우저 음성 세션에도 사용돼요.

**확인 필요**가 표시되거나 저장할 수 없다면 음성 모델 활성화, 제공자 키, 선택한 목소리와 TTS 모델의 호환성을 확인해요. 일반 사용자라면 관리자에게 모델·키 설정을 요청해요.

## 채널과 대화 설정

앱의 **채널**에서 Live Agent가 연결된 전화번호를 선택하고 **음성 프로필**을 지정해요. 새 번호를 연결할 때도 사용할 프로필을 선택해요. 웹챗 생성 화면에도 프로필 선택 항목이 있지만 **현재 텍스트 웹챗에는 음성이 적용되지 않아요**. [채널 연결 방법](/operations/channels)에서 번호와 웹챗 선행조건을 확인해요.

앱의 **대화 설정**(`/dashboard/settings/conversation`)은 Agent별이 아닌 **계정 공통** 설정이에요. 개인정보 마스킹과 원문 암호화 보관 여부, 종료 메시지·종료 감지 문구, 최대 통화 시간·침묵 종료, 무음 재확인(원문/AI 생성·간격·횟수), 경과 시간 안내·종료 액션을 설정하고 **설정 저장**을 눌러요. 원문 암호화 보관과 마스킹은 서로 다른 옵션이에요.

<Note>
새 **음성 세션이 시작될 때** 프로필 revision과 목소리·STT/TTS·대화 설정이 해당 대화에 고정돼요. 진행 중인 통화에 프로필이나 계정 설정 변경이 적용되지는 않아요. 최대 통화 시간은 계정 설정과 사용 가능한 시간 한도 중 짧은 값으로 제한돼요.
</Note>

연결된 번호로 **새 통화**를 시작해 목소리와 종료 동작을 확인해요. 음성이 나오지 않으면 먼저 채널에 연결된 프로필의 **사용 가능** 상태와 Agent의 현재 Live 배포를 확인해요. 기본 프로필, 채널에 연결된 프로필, 진행 중 세션에서 사용하는 프로필은 삭제할 수 없어요.

## 내 음성

TTS 제공자가 **Cartesia**이고 해당 키가 준비된 경우에만 **내 음성 관리**에서 이름과 WAV·MP3·WEBM 파일(10 MiB 이하)을 업로드해요. 등록한 음성이 **사용 가능**으로 표시되면 Cartesia 프로필의 **사용할 음성**에서 선택하고 저장해요. 파일 확장자와 MIME 형식이 일치해야 하며, 프로필이나 진행 중 세션에서 쓰는 내 음성은 삭제할 수 없어요.
