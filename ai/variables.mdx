---
title: "대화에 변수 사용하기"
description: "시스템 값, 고객별 입력값과 REST 응답값을 Agent에 연결해요"
---

Agent마다 다른 날짜·고객 정보나 이전 도구의 응답을 쓰려면 먼저 [Agent 편집기](/ai/agents)의 **시스템 프롬프트** 또는 **첫 인사**에서 `{{이름}}` 형태로 참조해요. 로그인한 뒤 **변수** 화면에서 시스템 변수를 검색하고 복사할 수 있어요.

## 1. 자동으로 채워지는 값을 골라요

| 변수 | 값과 사용 범위 |
| --- | --- |
| `{{오늘}}`, `{{지금시각}}`, `{{요일}}`, `{{지금}}` | 한국 시간(KST)의 날짜·시간·요일이에요. `{{오늘+1}}`처럼 날짜에 ±366일까지 오프셋을 줄 수 있어요. |
| `{{연}}`, `{{월}}`, `{{일}}`, `{{달력}}` | 연·월·일, 오늘부터 14일간의 한국어 달력이에요. 달력은 시스템 프롬프트에 넣으세요. 첫 인사에 쓰면 날짜들을 모두 읽을 수 있어요. |
| `{{고객전화번호}}`, `{{통화방향}}` | 전화번호는 **전화에서만** 있고 웹챗에서는 빈 값이에요. 통화방향은 인바운드 또는 아웃바운드예요. |

## 2. 대화마다 입력할 값을 지정해요

프롬프트나 첫 인사에 `{{order_id}}`처럼 새 이름을 넣으면 사용자 변수로 인식해요. Agent 테스트 또는 발신 시작 전에 나타나는 **대화 변수** 입력창에서 값을 입력하고 문자열·숫자·참/거짓 유형을 골라 시작해요. 전화 발신에서 해당 고객의 저장된 값이 미리 채워졌다면 이번 통화의 값으로 수정할 수 있어요. 저장된 고객 값은 **고객 관리 > 고객 상세 > 고객 속성**에서 확인·수정해요. 같은 고객의 저장 값을 다음 대화에 사용하거나 상담 뒤 추출하려면 해당 Agent의 **고객 메모리**를 켜야 해요. 이번 대화에 입력한 값은 같은 이름의 저장 값보다 우선해요.

## 3. 앞선 REST 응답을 다음 도구에 연결해요

[REST 도구](/ai/tools)에 **출력 JSON Schema**를 설정하면 숫자·문자열·불리언 같은 단일 값 필드가 `api.<functionName>.<field>` 후보가 돼요. Agent 노드에서 값을 받을 REST 도구의 **값 출처**(양방향 화살표)를 열고 **요청 인자**나 URL의 `{{변수}}` 부분에 앞 도구의 응답 변수를 연결해요. 앞 도구가 먼저 실행되어 값을 반환해야 사용할 수 있어요. Handoff 경로에서 넘긴 변수도 도달 가능한 후속 노드에서 값 출처로 선택할 수 있어요.

Agent를 **Deploy**하고 새 대화를 시작해 입력값이 응답에 반영되는지 확인해요. 누락되면 입력창의 필수 값을 채우고, 도구 URL의 출처가 연결됐는지 확인해요. 사용자 변수는 최대 **50개**, 이름 **64 UTF-8 바이트**, 문자열 값 **1,000 UTF-8 바이트**예요. 시스템 이름과 `api.` 등 예약 네임스페이스는 사용자 변수 이름으로 사용할 수 없어요.
