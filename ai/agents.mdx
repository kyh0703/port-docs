title: "에이전트"
description: "직접 또는 AI 초안으로 Agent를 만들고, 텍스트 테스트 후 현재 Live 버전을 확인해요"
---

로그인한 뒤 앱의 **에이전트**(`/agents`)에서 Agent를 만들어요. 편집한 초안은 고객 대화에 바로 적용되지 않아요. **Deploy**로 현재 Live 버전을 지정한 뒤 새 대화로 확인해요.

## 생성 방식

**에이전트 추가**를 누르고 아래 중 하나를 선택해요.

| 방식 | 진행 방법 | 결과 |
| --- | --- | --- |
| **직접 만들기** | 이름을 입력하고 **관리자 모드(Supervisor)** 또는 전환 모드(Handoff)를 골라 **생성**해요. | 비어 있는 Agent 편집기로 이동해요. |
| **AI로 초안 만들기** | 업무 목표, 실행 모델, **도구 없이** 또는 **직접 선택**한 도구를 지정하고 **초안 생성**을 눌러요. 생성된 이름·노드·실행 경로·경고를 검토한 다음 **이 초안으로 만들기**를 눌러요. | **Handoff 모드 초안**을 편집할 수 있어요. AI 생성은 Supervisor 모드를 만들거나 도구를 자동 선택하지 않아요. |

## 노드와 연결

노드를 추가하고 연결한 다음, 각 노드를 눌러 이름·실행 모델·시스템 프롬프트와 필요한 [도구](/ai/tools)를 설정해요. 시작 노드에는 첫인사를 넣을 수 있어요. 연결선을 누르면 오른쪽에서 경로 조건을 편집할 수 있어요.

- **Supervisor**: 총괄 노드에서 specialist 노드로 연결하고 **관계 설명**과 `Context`를 지정해요. 총괄이 specialist에게 작업을 맡기고, specialist의 완료 요약을 총괄에게 돌려줘요. `Conversation`은 이전 대화 내용을 전달하고 `None`은 전달하지 않아요.
- **Handoff**: 시작 노드에서 대상 노드로 연결하고 **Condition**과 전달할 대화 맥락을 정해요. 필요하면 시작·완료·실패 안내와 Parameters를 설정해요. 조건에 따라 **다른 Agent 노드가 대화 주도권을 이어받아요**.

<Note>
Handoff는 Agent 간 전환이지 사람 상담원에게 전화를 넘기는 기능이 아니에요. 사람 연결은 별도의 SIP 음성 통화 설정이 필요하며, 편집기의 텍스트 테스트와 웹챗에서는 사람 연결 도구가 실행되지 않아요.
</Note>

## 테스트와 배포

| 상태 | 어떻게 만들어지나요? | 고객에게 적용되나요? |
| --- | --- | --- |
| **초안** | 캔버스에서 편집해요. 수정 내용은 배포 또는 테스트 준비 때 서버 초안으로 저장돼요. **Discard**는 마지막 저장 초안으로 되돌려요. | 아니요. |
| **테스트 revision** | 첫 배포 후 편집기의 **테스트**를 누르면 현재 초안을 저장하고 고정된 새 배포 revision으로 텍스트 대화를 시작해요. | 아니요. 현재 Live를 바꾸지 않아요. |
| **현재 Live** | **Deploy**로 새 revision을 배포하거나 **배포 관리**에서 활성화된 이전 revision을 선택해요. | 예. 새 대화에서 사용해요. |

처음에는 필수 설정을 채워 **Deploy**해야 편집기에서 테스트할 수 있어요. 그 뒤 **테스트**에서 필요한 프롬프트 변수 값을 입력하고 질문해요. 대화 내용과 참여/전환한 노드, 실행 기록을 확인한 뒤 만족하면 다시 **Deploy**해요. **배포 관리**의 **현재 Live** 표시와 [운영 배포본 Live 테스트](/ai/evaluations)를 확인하고, [채널](/operations/channels)에서 새 대화를 시작해 변경이 적용됐는지 확인해요. 편집기 테스트가 통과해도 자동 배포되지는 않아요.

## 배포 오류

- 노드의 이름·프롬프트·실행 모델, 시작 노드와 연결을 확인해요. Supervisor는 총괄 1개와 specialist 1개 이상, 각각의 관계 설명이 필요해요. Handoff는 모든 노드가 시작 노드에서 도달 가능해야 하고 각 경로에 Condition과 올바른 대화 맥락이 필요해요.
- 음성 Agent 배포에는 OpenAI 계열 실행 모델이 필요해요. API 도구 URL 변수에 값 출처가 없으면 경고를 확인하고 값을 연결하거나 **확인 후 배포**해야 해요.
- Live 대상이 보이지 않으면 **배포 관리**에서 현재 Live가 있는지 확인해요. 테스트용 revision만 만들었다면 **Deploy** 또는 활성 revision 승격이 필요해요.
